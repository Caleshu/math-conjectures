## Original conjecture

{\em Calculate $\alpha_=(\hyp{n})$.}

**Normalized statement.** Determine $\alpha_=(Q_n)$ for all $n$: the maximum size of an independent set of $Q_n$ that contains equally many vertices of even and of odd Hamming weight.

## Definitions

- **equi-independence number $\alpha_=(G)$**: For a bipartite graph $G$: the cardinality of a maximum independent set with half of its vertices in each bipartition class.

Step 4 (upper bound). By Harper (C4) at $k=\kappa$: $\Phi_m(\kappa)\ge|N[S_\kappa]|$. The set $S_\kappa$ itself shows $\le$, so $g(\kappa)=2^m$. By Step 2, $\kappa(m)=\kappa$. (Equivalently, Harper at $\kappa+1$ together with the explicit count gives $g(\kappa+1)\ge2^m+r+1$.) So for $r\ge1$: $\alpha_=(Q_{2r+1})=2\kappa(2r)=4^r-\binom{2r}{r}$ and $\alpha_=(Q_{2r+2})=2\kappa(2r+1)=2(4^r-\binom{2r}{r})$.

Step 5 (r = 0, i.e. n = 1, 2). $Q_1=K_2$: a balanced set of size 2 would be an edge, so $\alpha_==0$. In $Q_2=C_4$ each even vertex is adjacent to both odd vertices, so $\alpha_==0$. Both agree with the formula, since $4^0-\binom00=0$. In the reduced picture: $m=0$, $g(1)=2>1$; $m=1$, $g(1)=3>2$.

Step 6 (constructions, Harper-free). Let $n\ge1$ and $s=\lfloor(n-1)/2\rfloor$, so $n-2s\ge1$. Let $C=[2s]$ and write $w(x)=|x\cap C|$. Set $I=\{x\in E:w(x)\le s-1\}\cup\{y\in O:w(y)\ge s+1\}$. Edges join only $E$ to $O$. If $x\in E$ and $y\in O$ are in $I$, then $d(x,y)\ge|w(y)-w(x)|\ge2$. So $I$ is independent. For each pattern on $C$ there are $2^{n-2s}$ completions, half of each parity. Hence $|I\cap E|=2^{n-2s-1}\sum_{i\le s-1}\binom{2s}{i}=2^{n-2s-2}(4^s-\binom{2s}{s})$, and $|I\cap O|$ is the same by complementation on $C$. So $|I|=2^{n-1}-2^{n-1-2s}\binom{2s}{s}$, which matches Step 4 for both parities. Checks: $n=6$, $s=2$: $32-2\cdot6=20$. $n=7$, $s=3$: $64-20=44$.

Conclusion: $\alpha_=(Q_n)=2^{n-1}-2^{n-1-2s}\binom{2s}{s}$ for all $n\ge1$, assuming Harper at the two sizes above. The middle-levels sub-claim C-02b9f4 is not used.

## Failed approaches

- **Full-layer constructions only: unions of non-consecutive weight layers of $Q_n$** (strategist): Optimal only in some cases (e.g. $n=5$ with layers $\{1,4\}$, $n=7$ with $\{0,2,5,7\}$). For $n=6$ the best layer union gives 12, but partial layers are needed to reach 20.
- **Spectral / expander-mixing (Hoffman-type) bihole bound** (strategist): It gives only $\alpha_=\le 2^{n-1}(n-2)/(n-1)$, a deficit of order $2^n/n$. The true deficit is of order $2^n/\sqrt n$, so this cannot give the exact value.
- **Using Harper directly on $Q_n$ with $A\subseteq E$** (strategist): Harper's minimisers (balls) are not contained in one parity class. Folding to $Q_{n-1}$ (C1) is what turns the parity-restricted problem into the unrestricted closed-neighbourhood problem.
- **Level-threshold sets in Q_n itself (all even vertices of weight <= t together with all odd vertices of weight >= t+3)** (extremal): This is valid but suboptimal. Using full Hamming weight wastes a whole level on each side of the gap. The optimal construction thresholds only the weight of a prefix of length 2s and leaves the last 1 or 2 coordinates free, which is what the double-cover reduction shows.
- **Derive the $m=2r+1$ isoperimetric bound from the $m=2r$ ball bound by splitting $Q_{2r+1}=Q_{2r}\times K_2$, using $|N[A]|\ge|N[A_0]|+|N[A_1]|$.** (extremal): This works only when $|A_0|=|A_1|=|B_{r-1}|$. Unbalanced splits would need $\Phi_{2r}(a)+\Phi_{2r}(2b-a)\ge2\Phi_{2r}(b)$, a convexity property the Harper profile does not have in general. So Harper's theorem at an intermediate size in $Q_{2r+1}$ is still used.
