# Erdős Problem 64 (Erdős–Gyárfás conjecture)

**Status:** Open

## Statement

Does every finite graph with minimum degree at least $3$ contain a cycle of length $2^k$
for some $k \geq 2$?

In other words: must every graph in which each vertex has at least three neighbours
contain a cycle of length 4, 8, 16, …?
