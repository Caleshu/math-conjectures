# Gonality of the 6-dimensional hypercube

**Status:** **gon(Q₆) = 32**, by a computer-assisted proof (`PROOF.md`; the full write-up is the author's PDF).
I re-ran all the computations and they agree. Part of the proof is formalized in Lean:
`Basic.lean` and `Certs.lean` build. **`Main.lean` (the theorems marked Lean below) will be added once its build
finishes**, so those entries are not confirmed yet.

## Statement

The (divisorial) gonality of a graph G is the minimum degree of a divisor of positive rank in chip-firing on G. The upper
bound gon(Q₆) ≤ 32 is classical: put one chip on each vertex of one bipartite class. The content is gon(Q₆) ≥ 32.

## Proof outline (see `PROOF.md`)

- **Harper's edge-isoperimetric inequality:** sets of 11 to 53 vertices have edge boundary at least 32.
- **Eggs and cuts:** the scramble-number argument of Harp–Jackson–Jensen–Speeter, reused.
- **Lemma 2** (computer): every vertex set of size ≤ 31 misses some egg.
- **Lemma 3** (computer): none of the 130 divisors 5·1_{N(0)} + R and 2·1_{S₂(0)} + R, where R is empty or a single chip,
  has positive rank.

## What is checked, and how

| Part | Check |
|---|---|
| Lemma 3 (130 divisors) | **Lean**: `lemma3`. Each divisor has a rank-0 certificate (firing script + Dhar burning order), and `not_posRank_of_certOK` (`Basic.lean`) proves that certificates are sound. Also re-run in C (`c2.c`) and Python (`special.py`): 0 of 130 have positive rank. |
| Harper bound values for m = 10..53 | **Lean**: `harper_values` (arithmetic only). Re-run with `eggcut.py`. |
| Strict supersets of N[0] with ≤ 10 vertices have boundary ≥ 32 | **Lean**: `closedNbhd_strict_superset` |
| Lemma 2 (exhaustive search) | **C, two independent programs**: `dfs3.c` (16 chunks, 29,771,753,493 nodes) and `dfsB.c` (32 chunks, 28,648,477,594 nodes). Both report NONE. Logs are in `computations/logs/`. Not in Lean. |
| Harper's theorem itself, the egg/scramble argument | **Paper only**, not formalized |

Note on `eggcut.py`: it prints a minimum of 30 for strict supersets, because it includes the r = 0 case (N[0] itself).
The strict-superset minimum is 32, as used in the proof.
