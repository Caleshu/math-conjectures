## Original conjecture

{\em Let $n\geq 2$ and let $k$ be an even integer with $2 \le k \le 2^{n-1}$. A vector $v \in \hyp{k}$ is the parity vector of a Hamiltonian cycle of $\hyp{n}$, i.e. $v=\beta_i(h)$ for some $i$ and Hamiltonian cycle $h$, if and only if it contains the same number of $0$'s and $1$'s.}

**Normalized statement.** Let $n\ge2$ and let $k$ be an even integer with $2\le k\le 2^{n-1}$. Conjecture: for every $v\in\{0,1\}^k$, there exist a Hamiltonian cycle $h$ of $Q_n$ and a dimension $i$ with $\beta_i(h)=v$ (in particular $c_i(h)=k$) if and only if $v$ has exactly $k/2$ zeros and $k/2$ ones.

## Source

Feliú Sagols, Guillermo Morales-Luna, *Parity balance of the $i$-th dimension edges in Hamiltonian cycles of the hypercube* (2010), arXiv:1009.3304, doi:10.48550/arxiv.1009.3304

## Definitions

- **$\lambda_i(h)$**: After rotating/reversing $h$ so that $h_0h_1$ is an $i$-th dimension edge with $(h_0)_i=0$: the list $[j_0=0,j_1,\dots,j_{c_i-1}]$ of indices $\ell$ at which an $i$-th dimension edge $h_\ell h_{\ell+1}$ starts.
- **$\mathit{par}_{in}(v)$**: Parity of the Hamming weight of $v$ after deleting its $i$-th coordinate.
- **parity list $\beta_i(h)$**: $[b_0,\dots,b_{c_i-1}]$ with $b_0=\mathit{par}_{in}(h_0)$ and $b_k=(b_{k-1}+j_k-j_{k-1}+1)\bmod 2$. Equivalently, $b_k=\mathit{par}_{in}(h_{j_k})$.

**Setup.** Let $h$ be a Hamiltonian cycle of $Q_n$, normalised so that its $i$-edges are $e_0,\dots,e_{k-1}$ in cyclic order. The tail of $e_m$ is $h_{j_m}$, and it lies on side $m \bmod 2$. Define segment $m$ as the subpath from the head of $e_{m-1}$ to the tail of $e_m$. It lies entirely in the subcube on side $m \bmod 2$ and has $j_m-j_{m-1}$ vertices.

**Fact 1 (every segment has at least 2 vertices).** If a segment had one vertex, that vertex would lie on two $i$-edges. This is impossible, because each vertex of $Q_n$ has only one $i$-neighbour.

**Fact 2 (consecutive bits fix a segment's parity).** A path in the bipartite graph $Q_{n-1}$ changes parity at every step. So $b_m=b_{m-1}$ exactly when segment $m$ has an odd number of vertices, and then it has at least 3. This matches the paper's recurrence $b_m=b_{m-1}+j_m-j_{m-1}+1$.

**Fact 3 (parity classes on each side balance).** The segments on one side partition that copy of $Q_{n-1}$, whose two parity classes have the same size. An odd segment whose endpoints both have parity $p$ has one more vertex of parity $p$ than of the other parity, while an even segment is balanced. So on each side, the number of positions with $b_{m-1}=b_m=0$ must equal the number with $b_{m-1}=b_m=1$.

**Necessary conditions.** For each side $s\in\{0,1\}$, write $\mathrm{same}_s$ and $\mathrm{diff}_s$ for the number of positions $m\equiv s \pmod 2$ with $b_{m-1}=b_m$ and $b_{m-1}\ne b_m$ respectively, so $\mathrm{same}_s+\mathrm{diff}_s=k/2$. A parity vector must then satisfy:
- **(A)** it is balanced (the paper's result);
- **(B)** for each side, the same-0 count equals the same-1 count (Fact 3);
- **(C)** $3\,\mathrm{same}_s+2\,\mathrm{diff}_s\le 2^{n-1}$ for each side (Facts 1 and 2).

**Counterexample.** Take $k=2^{n-1}$. Condition (C) then forces $\mathrm{same}_s=0$, so $\beta_i(h)$ must alternate. Hence for $n=3$, $k=4$, the balanced vector $v=0011$ is not $\beta_i(h)$ for any $h$ or $i$, even allowing cyclic rotation. More generally, for $k\ge 4$ the balanced vector $0^{k/2}1^{k/2}$ has $\mathrm{same}_0+\mathrm{same}_1=k-2$, so it fails whenever $3k>2^n+2$. Only $n=2$ survives, where $k=2$ and both $01$ and $10$ occur.

## Failed approaches

- **Strong version: every gap-length profile $L$ with $L_t\ge1$, $L_t\equiv v_t+v_{t+1}$ and correct half-sums is realizable.** (strategist): False already for $n=4$, $v=001011$, $L=(2,3,1,1,2,1)$: a degree argument in $Q_3$ (C8). So slack placement is genuinely constrained, and inductive invariants of the form 'slack can be put at any gap' fail.
- **Inductive generation using only word-level merge rules (gap lengths ignored, only the forced lower bounds used).** (strategist): From $S_3=\{01,0101\}$ these rules give only alternating words of length 4 at $n=4$. They miss $0011$, which is realizable because the $k=2$ cycle of $Q_3$ has gaps of length 3. Gap-length information must be tracked.
- **Halving induction: write every vector satisfying (N) at level $n$ as an M1/M2 merge of two vectors satisfying (N) at level $n-1$.** (strategist): Cases where (N) holds with equality need exact load balance in both halves plus letter balance: three equations, two cut parameters. Concretely, $000111$ at $n=4$ is not a concatenation of alternating arcs, and its realizations cross the merging direction more than twice.
- **Using only the prism $C\times K_2$ over a Hamiltonian cycle $C$ of $Q_{n-1}$.** (strategist): The Hamiltonian cycles of a prism use either 2 rungs or all rungs, so only $k=2$ or alternating $k=2^{n-1}$ arise.
- **Realize general vectors using only one Hamiltonian cycle $H$ of $Q_{n-1}$ (Hamiltonian cycles of the prism $H\square K_2$).** (extremal): The prism over a cycle $C_N$ has Hamiltonian cycles with $c=2$ or $c=N$ only, so it gives just alternating vectors of lengths 2 and $2^{n-1}$. Chords of $Q_{n-1}$ are needed.
- **Monotonicity via the standard doubling (two copies of $h$ joined across a new dimension).** (extremal): It doubles $c_i$ (both copies contain the dimension-$i$ edges). Instead, the new dimension has to be inserted inside the layers by replacing a path edge with a detour (C7).
- **Looking for an extra parity obstruction from requiring each subcube to be split evenly between the two parities of $par_{in}$, applied to the even-indexed and odd-indexed segments separately** (construction): In the cyclic setting this per-subcube parity condition follows from being balanced (C8), so it gives no new obstruction. The real obstruction is the length count.
