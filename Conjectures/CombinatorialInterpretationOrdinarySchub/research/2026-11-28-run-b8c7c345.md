## Definitions

- **Schubert polynomial**: $\mathfrak S_u$ is the polynomial representative indexed by $u$ of a Schubert cohomology class. The ordinary structure constants are the coefficients of products in this basis.

The code rejects a subword as soon as a selected swap decreases length. A PASS record gives the number of matched pairs on each directed weight edge. To recover an explicit object matching, sort the mask triples within each fiber, process the recorded edges in lexicographic order, and pair the next indicated number of unused objects at their two endpoints. A FAIL record gives the odd types in a deficient subset and all their even neighbor types, each with its multiplicity. To convert its factor triple back to the question's notation use $(u,v,w)=(p,q,w_0r)$.

```python
from collections import Counter, defaultdict
from itertools import combinations_with_replacement, permutations, product


def rank_five_certificates():
    board = [(i, j) for i in range(1, 5) for j in range(4, i - 1, -1)]
    poly = defaultdict(Counter)
    length = {}
    for mask in range(1 << len(board)):
        p = list(range(1, 6))
        wt = [0] * 4
        for k, (i, j) in enumerate(board):
            if mask & (1 << k):
                if p[j - 1] > p[j]:
                    break
                p[j - 1], p[j] = p[j], p[j - 1]
                wt[i - 1] += 1
        else:
            perm = tuple(p)
            poly[perm][tuple(wt)] += 1
            length[perm] = sum(wt)

    weights = {t for t in permutations((4, 3, 2, 1)) if t[3] <= 3}
    def odd(t):
        return sum(t[i] < t[j] for i in range(4) for j in range(i + 1, 4)) % 2
    left = sorted(t for t in weights if odd(t))
    adj = {}
    for a in left:
        adj[a] = []
        for i in range(3):
            b = list(a)
            b[i], b[i + 1] = b[i + 1], b[i]
            if tuple(b) in weights:
                adj[a].append(tuple(b))

    def certify(m):
        flow, used = Counter(), Counter()
        for root in left:
            for _ in range(m[root]):
                parent = {root: None}
                queue = [root]
                for x in queue:
                    if x in adj:
                        neighbors = adj[x]
                    elif used[x] < m[x]:
                        break
                    else:
                        neighbors = [a for a in left if flow[a, x] > 0]
                    for y in neighbors:
                        if y not in parent:
                            parent[y] = x
                            queue.append(y)
                else:
                    U = sorted(a for a in left if a in parent)
                    V = sorted({b for a in U for b in adj[a]})
                    assert sum(m[a] for a in U) > sum(m[b] for b in V)
                    return 'FAIL', ([(a, m[a]) for a in U], [(b, m[b]) for b in V])
                used[x] += 1
                while parent[x] is not None:
                    y = parent[x]
                    if y in adj:
                        flow[y, x] += 1
                    else:
                        flow[x, y] -= 1
                    x = y
        return 'PASS', sorted((a, b, d) for (a, b), d in flow.items() if d)

    for p, q, r in combinations_with_replacement(sorted(poly), 3):
        if length[p] + length[q] + length[r] != 10:
            continue
        m = Counter()
        for a, b, c in product(poly[p], poly[q], poly[r]):
            t = tuple(x + y + z for x, y, z in zip(a, b, c))
            if t in weights:
                m[t] += poly[p][a] * poly[q][b] * poly[r][c]
        tag, data = certify(m)
        yield (p, q, r), tag, data
        if tag == 'FAIL':
            return
```

The search from an unsaturated negative type traverses every forward weight edge and the reverse of every edge carrying positive flow. Reaching free even capacity increases the matched total by one. If the search exhausts its queue, all neighbors of its reached negative types are saturated and all flow entering those neighbors originates among the reached types. The root still has an unmatched object. This proves the strict Hall deficiency asserted in the FAIL branch. The procedure works independently of the module-theoretic special case.
