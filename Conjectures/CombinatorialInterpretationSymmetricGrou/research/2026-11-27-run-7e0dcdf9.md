## Original conjecture

The sum has one term per conjugacy class, without class-size weights. The problem asks for a combinatorial interpretation of $R(\lambda)$.

**Normalized statement.** Give an explicit family of finite combinatorial sets $\mathcal T(\lambda)$ such that for every integer $n\geq1$ and every $\lambda\vdash n$, $|\mathcal T(\lambda)|=R(\lambda)=\sum_{\rho\vdash n}\chi^\lambda(\rho)$.

**Claim.** `author_support = proved_here`. For every $n\geq 1$ and $\lambda\vdash n$, the following set $\mathcal T(\lambda)$ has cardinality $R(\lambda)$.

For each $\rho\vdash n$, take the permutation $g_\rho$ whose cycles are consecutive blocks of labels $1,\ldots,n$ of the lengths in $\rho$, read in increasing order within each block. Fill the diagram of $\lambda$ bijectively with those labels. Use all fillings $F$ that increase down each column, ordered lexicographically by reading successive columns from top to bottom.

Associate an integer vector $v_\rho(F)$ to each filling. For every permutation $s$ of the entries within the columns, read the row numbers of the labels of $sF$ around each cycle of $g_\rho$. Treat each resulting word up to cyclic rotation, retaining its direction. The multiset $N$ of these necklaces is a vector coordinate. Add $\operatorname{sgn}(s)$ to coordinate $N$, starting all coordinates at zero. Include $(\rho,F)$ in $\mathcal T(\lambda)$ exactly when appending $v_\rho(F)$ to the earlier vectors for this $\rho$ increases their rank over $\mathbb Q$. This is a finite test on combinatorial data. Equivalently, the rank of each prefix is the largest order of a square minor with nonzero integer determinant. No efficiency bound is asserted.

**Justification.** Use the Specht realization of $V^\lambda$ inside the vector space on row tabloids. A row tabloid records just the row number of each label. The polytabloid of $F$ is the signed sum of its tabloids under permutations within its columns. By the definition of the Specht module, all polytabloids span it. Sorting each column changes a polytabloid only by a sign, so the fillings used above still span it.

Write $Z_\rho$ for the centralizer of $g_\rho$. A permutation commuting with $g_\rho$ can send a cycle to any cycle of the same length. Once the image of one label on that cycle is chosen, commutation determines all remaining images around it. Thus two tabloids are in the same $Z_\rho$-orbit exactly when they have the same necklace multiset. Averaging a tabloid over $Z_\rho$ gives the uniform average on its orbit. These orbit averages are linearly independent because their supports are disjoint. In this basis, the averaged polytabloid of $F$ has precisely the coordinates $v_\rho(F)$. Averaging projects the Specht module onto its invariant subspace, so the number of rank increases for $\rho$ equals $\dim (V^\lambda)^{Z_\rho}$.

Taking the trace of that averaging projection gives $\dim (V^\lambda)^{Z_\rho}=|Z_\rho|^{-1}\sum_{h\in Z_\rho}\chi^\lambda(h)$. Each conjugate of $g_\rho$ gives the same average, and its class has size $n!/|Z_\rho|$. Consequently the total count is $\frac{1}{n!}\sum_{g\in S_n}\sum_{h:gh=hg}\chi^\lambda(h)=\frac{1}{n!}\sum_{h\in S_n}|Z(h)|\chi^\lambda(h)=\sum_{\tau\vdash n}\chi^\lambda(\tau)$. The last equality follows because the class of $h$ has size $n!/|Z(h)|$. This proves the identity for all the stated shapes, including $n=1$.
