# Digital anomalies

**Status:** Question (a) **solved: there are infinitely many two-digit anomalies**, Lean-verified
(`Main.lean`, `infinitely_many_two_digit`). This disproves the paper's Conjecture 4.6.
Question (b) (any anomaly with $k \ge 3$ digits?) is open.

## Statement

Positive integers $(x, y, B)$ with $B \ge 2$ form a *digital anomaly* if
$$\frac{x}{y} = y + \frac{x}{B^k},$$
where $k$ is the number of base-$B$ digits of $x$ ($B^{k-1} \le x < B^k$). In words: dividing
$x$ by $y$ writes $y$, then a radix point, then the digits of $x$. Example: $5 / 2 = 2.5$.

Source: Samer Seraj, *Diophantine Analysis of a Digital Anomaly*, arXiv:2512.06056
(December 2025). Conjecture 4.6: the only solutions with $k = 2$ are $(18, 4, 6)$ and
$(1323, 36, 42)$. The shortlist notes found more by computer, e.g. $(20808, 144, 204)$, and
asked: (a) are there infinitely many with $k = 2$? (b) is there any with $k \ge 3$?

## Result: an infinite family

**Theorem.** If $p^2 = 8v^2 + 1$ with $v \ge 1$, then
$$B = 2vp, \qquad y = 4v^2, \qquad x = 2v^2p^2 = B^2/2$$
is a digital anomaly with $k = 2$.

*Proof.* $B \le B^2/2 < B^2$, so $x$ has two base-$B$ digits and $x / B^2 = 1/2$. Then
$x / y = p^2 / 2 = (8v^2 + 1)/2 = 4v^2 + \tfrac12 = y + x/B^2$. $\square$

The Pell equation $p^2 - 8v^2 = 1$ has infinitely many solutions,
$(3,1), (17,6), (99,35), (577,204), \dots$, generated by $(p, v) \mapsto (3p + 8v,\ p + 3v)$.
They give

| $(p, v)$ | $(x, y, B)$ |
|---|---|
| (3, 1) | (18, 4, 6) |
| (17, 6) | (20808, 144, 204) |
| (99, 35) | (24012450, 4900, 6930) |
| (577, 204) | (27710346528, 166464, 235416) |

**Lean** (`Main.lean`): `IsAnomaly k x y B` is the definition above, with the equation in
$\mathbb{Q}$. `anomaly_of_pell` is the theorem, and `infinitely_many_two_digit : ∀ N, ∃ x y B,
N < B ∧ IsAnomaly 2 x y B` follows from the Pell recursion. The file also checks the paper's
two solutions.

### A broader family

The second paper solution $(1323, 36, 42)$ is not of this form. All known two-digit
solutions fit a wider pattern: $B = pM$, $y = M^2$, $x = M^4p^2/(p^2 - 1)$ for integers
$p > M \ge 1$ with $(p^2 - 1) \mid M^4$. (Check: $B^2 - y = M^2(p^2-1)$, and
$x(1/y - 1/B^2) = y$.) The Pell family is the case $p^2 - 1 = 8v^2$, $M = 2v$.
`computations/family.py` lists the 156 such solutions with $p < 200{,}000$.

## Question (b): $k \ge 3$

The same idea ($x = B^k/2$) needs $B^k = y(2y + 1)$ with coprime factors, so
$y = a^k$ and $2a^k + 1 = b^k$. For $k = 3$, the Thue equation $b^3 - 2a^3 = 1$ has only
trivial solutions, so this family stops at $k = 2$. Question (b) stays open.
